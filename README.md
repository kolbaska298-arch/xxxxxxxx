# Anti-Raid Telegram Bot

Бот для групп и супергрупп на `aiogram 3.x`. Он ограничивает флуд викторинами, стикерами и медиа, игнорируя администраторов.

## Запуск

1. Установите Python 3.12+ и зависимости:

   ```powershell
   python -m pip install -r requirements.txt
   ```

2. Создайте переменную окружения с токеном бота:

   ```powershell
   $env:BOT_TOKEN = "токен_от_BotFather"
   ```

3. Добавьте бота в группу администратором с правом **ограничивать пользователей** и запустите:

   ```powershell
   python bot.py
   ```

Команда `/баненые` доступна администраторам и показывает активные автоматические муты. Сроки выводятся в локальном времени компьютера, на котором работает бот.

## Деплой на Railway

1. Загрузите проект в приватный GitHub-репозиторий.
2. В Railway выберите **New Project** -> **Deploy from GitHub repo** и укажите этот репозиторий.
3. В разделе **Variables** добавьте:
   - `BOT_TOKEN` — новый токен от BotFather;
   - `OWNER_ID` — Telegram ID владельца, например `8414885700`.
4. Railway автоматически установит зависимости и запустит `python bot.py`.

Для этого бота не нужно настраивать домен или порт: он работает через Telegram long polling.
